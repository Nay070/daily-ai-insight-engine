这批数据是我在线检索并逐条核对的结果。事件、日期、来源和 URL 均来自可追溯网页；`content` 是依据网页事实重新撰写的编辑性摘要，不是版权正文的复制。

采集时我把可核验性放在覆盖广度之前。具体顺序是：先找一手发布确认产品和技术事实，再用独立媒体补充产业、安全或应用视角，最后检查语言和来源类型是否过度集中。

## 来源选择理由

1. **近期性**：只保留日报日前 30 天内发布的内容，其中 8 条发表于最近 10 天。
2. **一手来源优先**：模型能力、产品上线和平台变更优先使用 OpenAI、Google DeepMind、Anthropic 和 GitHub 的官方页面。
3. **独立媒体校验**：Axios、Associated Press、新华网和中新网补充独立报道及国内产业落地信息，避免数据完全由厂商口径构成。
4. **中英文混合**：13 条英文、3 条中文，兼顾全球前沿发布和中国本地 Agent、数据、能源应用。
5. **信息密度**：每条摘要保留多个明确事实，优先选择包含功能、适用范围、评测结果、成本、时间或应用指标的页面，降低模型因信息过薄而给出低置信度的概率。
6. **可审计性**：每条数据都有唯一 URL、明确发布时间、来源类型和独立选择理由。
7. **稳定性**：社交媒体本轮未作为事实源，因为帖子可能删除、身份及时间信息不稳定；它更适合后续作为舆情信号，而非核心事实层。

## 核验说明

16 条均已核对标题、发布时间和关键事实。14 条通过原页面直接读取正文；Axios 和 Associated Press 两条通过精确文章 URL 的新闻搜索结果读取原文信息。两条媒体记录仍保留其原始文章直链，未使用二次转载地址。

本数据集不声称代表全网舆情。它是用于验证新闻洞察流水线的定向近期样本，官方渠道占比较高，适合做事实抽取和产品趋势分析；如需研究公众态度，我会另行增加经过二次核验的 Reddit、X 或知乎样本，并与事实层分开存储，避免把舆论信号当成产品事实。
